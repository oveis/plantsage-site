## FAQ

**Comment annuler mon abonnement ?**
Ouvrez l'app App Store → votre profil → Abonnements → Plantsage → Annuler. Ou dans Plantsage : Réglages → Abonnement → Gérer l'abonnement.

**Comment supprimer mes données ?**
Réglages → Réinitialiser toutes les données supprime tout de votre appareil et de notre serveur.
