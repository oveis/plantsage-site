_Zuletzt aktualisiert: 15. September 2026_

Plantsage („die App") wird von einem Einzelentwickler („wir") betrieben. Diese Erklärung beschreibt, welche Daten die App erhebt, wie sie verwendet werden und welche Wahlmöglichkeiten du hast.

## Welche Daten wir erheben

| Daten | Zweck | Wohin sie gelangen |
|---|---|---|
| Gartendaten (Beete, Pflanzen, Aufgaben, Aktivitäts- und Erntedaten — nur Text, keine Fotos) | Synchronisierung und Sicherung deines Gartens | Unser Server (AWS, gehostet in den USA) |
| Ungefährer Standort (nur während der Nutzung) | Ermittlung deiner Klimazone und lokales Wetter | Wird in eine Zone umgewandelt; Koordinaten werden mit Apple Weather zur Wetterabfrage genutzt |
| Fotos für Diagnose, Bestimmung oder Samen-Scan | KI-Analyse deiner Anfrage | Über unseren Server an Anthropics Claude API; nach der Verarbeitung nicht gespeichert. An Ernte- oder Aktivitätseinträge angehängte Fotos bleiben auf deinem Gerät und werden nie hochgeladen |
| Chat-Nachrichten an den KI-Gärtner | Generierung von KI-Antworten | Verarbeitung durch Anthropics Claude API über unseren Server |
| Gerätekennung (zufällige UUID) sowie bei Apple-Anmeldung deine Apple-Nutzer-ID und E-Mail | Konto, Synchronisierung, Abo-Erkennung | Unser Server |
| Abostatus | Freischaltung der Premium-Funktionen | Mit Apple verifiziert, auf unserem Server gespeichert |

Wir erheben **keine** Werbekennungen, nutzen keine Analyse- oder Tracking-SDKs und verkaufen deine Daten niemals.

## Dienstleister

Wir teilen Daten nur mit den für den Betrieb nötigen Auftragsverarbeitern: Apple (Anmeldung, Abos, Wetter über Apple Weather), Amazon Web Services (Hosting) und Anthropic (KI-Verarbeitung).

## Speicherung & Löschung

Deine Daten werden gespeichert, solange du die App nutzt. Über **Einstellungen → Alle Daten zurücksetzen** kannst du jederzeit alle Daten löschen — auch auf unserem Server. Für weitere Löschanfragen kontaktiere uns unter der unten stehenden Adresse.

## Kinder

Plantsage richtet sich nicht an Kinder unter 13 Jahren, und wir erheben wissentlich keine Daten von ihnen.
